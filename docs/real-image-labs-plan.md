# 真实图片与开源项目实验升级

用户要求：搜索 GitHub 开源项目，实际调用并展示，用真实实验图片替代仅合成的体验。

1. 公共界面：保留原理机制实验；在对应实验上方新增默认展开的真实数据实验。生命周期隔离，章节切换取消旧任务，显示项目、版本、图像来源和许可。
2. 004/005：实拍双目图像块匹配、视差、置信度和匹配代价；可获得合法校准数据时加入真实光度立体。
3. 006：真实照片颜色聚类、真实帧特征光流；接入固定版本开源视觉库。
4. 007/008：调用 TensorFlow.js 官方 MobileNet / COCO-SSD，对真实照片执行分类、特征和检测；模型加载单独显示进度与错误。能够复用的模型与运行时同源发布。
5. 教学：原始图像、计算过程、结果、参数和失效条件可检查；不将模型置信度称作正确率；上传只本机处理。
6. 验收：数值测试、真实资产出处与哈希检查、桌面/手机浏览器、真实模型推理、原24实验回归、发布后在线检查。更新源码/静态包/教师指南。

不把大型模型换成随机结果，不把外链列表当接入，不把人工变换的照片声称为实拍配对。
