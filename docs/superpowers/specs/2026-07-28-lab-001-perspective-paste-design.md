# LAB 001｜Perspective Paste：利用消失点与透视变换实现自然贴字设计文档

日期：2026-07-28  
品牌：Vision Hub  
栏目：LAB｜实战实验室  
项目代号：Perspective Paste

## 1. 项目目标

构建一个面向视觉初学者的低门槛实战项目：用户导入一张普通照片，在墙面、地面、广告牌、包装盒或显示屏等近似平面上点选四个角，输入文字或导入透明 PNG，即可生成具有正确透视关系、基础光照匹配和表面纹理融合效果的贴图结果。

项目同时提供：

1. **Python 教学版**：使用 OpenCV、Pillow 和鼠标回调实现四点选区、控制点拖动、单应性变换、混合与导出；
2. **浏览器体验版**：使用原生 HTML、CSS、JavaScript 与 Canvas，实现上传、实时预览、拖拽控制点和导出；
3. **公众号文章**：先展示效果，再讲消失点、单应性和真实感融合，最后引导读者复现；
4. **完整源码与示例素材**：包含示例背景、透明 PNG、快捷键说明、运行步骤和失败场景说明。

项目重点不是复刻 Photoshop，而是让读者通过一个直观结果理解：

> 四个点如何确定一个平面映射，消失点如何描述透视方向，单应性如何完成贴合，融合策略如何让结果看起来更自然。

## 3. 项目边界

### 首版必须支持

- 导入背景图片；
- 输入任意文字；
- 导入透明 PNG；
- 在背景图中点选四个控制点；
- 拖动四个控制点并实时预览；
- 自动统一控制点顺序为左上、右上、右下、左下；

- Normal、Multiply、Soft Light 三种基础混合模式；

## 6. 几何模块设计

### 6.1 四点排序

程序内部统一使用：

```text
左上 → 右上 → 右下 → 左下
```

排序不能只依赖横纵坐标极值；应以点集中心、角度和多边形方向联合判断，避免强透视场景下错误排序。

### 6.2 合法性检查

下列情况不得进入透视计算：

- 四边形自交；
- 任意三点近似共线；
- 面积小于背景图面积的设定下限；
- 控制点超出画布范围；
- 单应性矩阵条件数过大或接近奇异；
- 四边形过度狭长，导致输出严重压缩。

程序必须给出具体错误原因，而不是只显示“失败”。

### 6.3 单应性

素材矩形四角与目标四边形建立一一对应：

\[
\mathbf{x}' \sim \mathbf{H}\mathbf{x}
\]

Python 版使用 `cv2.getPerspectiveTransform` 与 `cv2.warpPerspective`。正文解释平面到平面的投影关系，不完整推导八参数求解过程；详细推导可放 Engineer Note。

### 6.4 消失点与教学辅助

目标四边形的两组对边分别延长，得到两个消失点。它们用于：

- 展示平面的两个主方向；
- 解释远近压缩；
- 绘制透视网格；
- 帮助用户判断控制点是否符合场景结构。

必须明确：

> 实际贴图通过四点单应性完成；消失点主要用于解释、判断与辅助显示。

## 7. 素材模块设计

### 7.1 文字

文字统一渲染为 RGBA 图层，支持：

- 中文与英文；
- 用户指定 `.ttf` 或 `.otf` 字体；
- 字号、颜色、透明度；
- 描边；
- 字间距与行间距；
- 横排与竖排；
- 透明边界裁剪。

项目不打包字体文件，只提供字体路径配置与系统字体选择说明。

### 7.2 透明 PNG

- 保留原 Alpha 通道；
- 无 Alpha 时自动补为完全不透明；
- 支持“铺满目标区域”和“保持比例留白”两种适配方式；
- 默认使用铺满，并提示可能造成拉伸。

## 8. 真实感融合设计

处理顺序固定为：

```text
素材生成
→ 透视变换
→ 亮度匹配
→ 环境色适配
→ 轻微模糊
→ 背景纹理调制
→ 阴影（可选）
→ 混合模式
→ Alpha 合成
```

### 8.1 混合模式

- **Normal**：海报、标签、彩色图案；
- **Multiply**：墙面文字、喷涂、深色 Logo；
- **Soft Light**：柔和标识与轻度纹理融合。

默认规则：文字使用 Multiply，透明 PNG 使用 Normal。

### 8.2 亮度匹配

- 比较目标区域与素材亮度；
- 计算受限增益；
- 默认限制在 `0.6–1.4`；
- 避免过度拉亮或压暗。

### 8.3 环境色适配

- 估计目标区域低频平均色；
- 以 `10%–25%` 强度作用于素材；
- 保护 Logo 原始色彩，不做强制全局染色。

### 8.4 模糊

- 默认范围 `0–2.5 px`；
- 随原图分辨率缩放；
- 只用于减少素材与背景锐度差异。

### 8.5 纹理保留

首版采用局部均值与高频残差的简化方法：

1. 获取目标区域灰度；
2. 计算局部低频亮度；
3. 提取高频明暗变化；
4. 用该变化调制透视后素材；
5. 再执行混合。

目标是让墙面裂纹、纸张纹理、包装反光部分穿透素材，而不是完整模拟物理材质。

### 8.6 阴影

阴影默认关闭，只用于海报、贴纸、立体标牌等场景。支持：

- X/Y 偏移；
- 模糊半径；
- 透明度。

## 9. 交互设计

### Python 快捷键

```text
鼠标左键      添加或选中控制点
拖动鼠标      调整控制点
鼠标右键      删除最近控制点
Enter         确认当前四边形
T             输入或修改文字
P             导入透明 PNG
G             开关透视网格
V             开关消失线
M             切换混合模式
[ / ]         调整透明度
B             调整模糊程度
S             保存结果
R             重置
Esc           退出
```

窗口左上角显示：模式、混合方式、透明度、模糊值和控制点数量。

### 实时预览策略

- 拖动期间使用降采样预览；
- 松开后生成全分辨率结果；
- 导出始终以原图分辨率重新渲染；
- 缓存文字/PNG 素材；
- 参数无变化时不重复生成；
- 预览与最终导出共享同一套几何和融合参数。

## 11. 错误处理与失败边界

### 运行时提示

- 四边形过窄：提示重新选择；
- 点位自交：高亮冲突边；
- 面积过小：提示扩大目标区域；
- 素材比例差异过大：提示切换“保持比例”模式；
- 字体路径无效：列出可用系统字体或要求重新选择；
- PNG 无法读取：说明格式或文件损坏；
- 导出失败：显示目标路径与系统错误信息。

### 能力边界

必须在文章和 README 中明确：

- 单应性只适合近似平面；
- 圆柱、衣物褶皱、曲面屏不能自然贴合；
- 前景遮挡需要额外蒙版；
- 强镜面反射和复杂光照不能由简单亮度匹配完全解决；
- 本项目为几何与图像融合教学工具，不等同于专业图像编辑软件。

## 12. 测试与验收

### 自动化测试

#### 几何测试

- 四点乱序后能稳定排序；
- 自交四边形被拒绝；
- 近共线点被拒绝；
- 单位矩形映射保持一致；
- 已知单应性映射误差在像素阈值内；
- 消失点计算与平行线特例处理正确。

#### 渲染测试

- 中文与英文文字可生成非空 Alpha 图层；
- PNG 无 Alpha 时正确补全；
- 透明边界裁剪正确；
- 保持比例与铺满模式输出尺寸符合预期。

#### 融合测试

- Normal、Multiply、Soft Light 输出范围合法；
- 透明度为 0 时结果等于背景；
- 透明度为 1 时符合混合定义；
- 亮度增益被限制在 `0.6–1.4`；
- 纹理强度为 0 时不改变素材；
- 阴影关闭时不生成阴影层。

### 人工验收
