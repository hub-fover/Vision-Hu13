# 真实图片实验升级验收

## 实现范围

- 005/02：OpenCV Aloe 实拍左右图，JSFeat 预处理/FAST，原创 SAD 视差与代价检查。
- 005/03、006/02：OpenCV 篮球官方光流帧对，调用固定提交 JSFeat 金字塔 LK。
- 006/01、04：实拍帧差，以及 NASA 照片 RGB KMeans 每轮聚类。
- 007各场景与008/01：官方 MobileNet V1 alpha1.0（1024维），ImageNet 分类、冻结特征训练/KNN。
- 008/02：官方 COCO-SSD lite_mobilenet_v2，真实模型推理与二次NMS。
- 004/03：真实照片预览，嵌入已发布 LAB007 Depth Anything 对照实验；明确不冒称SFS求解。

## 验收证据

85项原理数值测试、13项真实算法/资产测试、发布资源检查通过。原24实验桌面和390像素移动布局回归通过；真实浏览器推理、输入像素变化、聚类参数、JSON导出及模型无效图片阻断检查通过。

实测：MobileNet客厅样例 home theater 84.50%；冻结特征分类头两张不同照片交叉熵0.693147→0.110443；COCO人物样例检测2个人物，分数88.47%和47.24%。以上分数是模型输出，不是基准准确率。照片不存在真值时不报告mAP/几何误差。

独立审查发现并修复4项：图片未解码/失败时复用旧画布；模型升级后来源台账未更新；恢复官方样例的来源竞态；上传原始帧尺寸未校验。复审没有剩余关键问题。回归验证包含失败/取消加载保持来源、原始尺寸不一致拒绝、模型输入事务与标签快照。

## 限制

传统视差代码没有未知相机标定或一般极线估计；深度未标定不能输出米制距离。小样本训练并非大型数据集评测。006的MeanShift/PCA与008注意力/生成/图文对齐仍是下方机制实验，未接入真实CLIP或扩散模型。DepthAnything扩展需要联网访问既有LAB007及其固定版本权重，其余真实实验运行时与权重同源随课程部署。

发布记录以GitHub Actions和发布后线上浏览器报告为准，部署完成前不报告已经上线。
