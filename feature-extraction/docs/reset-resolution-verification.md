# 高清计算后的复位回归

本版范围为场景 01–10，不包含图像拼接及人脸相关模块。

## 问题与修复

场景 08 在高清计算后复位，质量控件恢复为 640，但已解码的内置照片缓存仍为 1280，导致实际输入及结果不能恢复初始状态。复位现在同时释放两张内置照片的缓存引用，再按恢复后的质量重新解码。

## 实际验证

新增真实 Chrome 浏览器回归：首次输入宽度 640 → 高清输入宽度 1280 → 复位宽度 640；复位结果 PNG 与首次结果逐字节相同。修复前测试实际失败（1280 ≠ 640），修复后通过。

完整 `npm test`：53 项通过，0 失败，0 跳过。包含十个场景的移动尺寸浏览器交互、真实 Worker、参数、阶段、导出、错误反馈和数值测试。此记录不代表全部课程需求已完成验收，也不等同于真机验收。
