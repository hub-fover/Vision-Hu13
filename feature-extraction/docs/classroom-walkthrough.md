# 课堂操作卡：特征提取01–10

先在项目根目录运行 `node scripts/serve.mjs`，再访问 `http://127.0.0.1:4180/`。无需登录、无需准备图片。启动服务必须成功；此文不表示当前服务器已在线。场景链接在页面“复制场景链接”按钮获取；教师模式可在网址增加 `&teacher=1`。

每次先点“复位全部”，做一次参数变化，再用单步看真实中间阶段。以下是课堂操作路线，不是全场景浏览器验收已通过声明。

|场景|先做一个操作|对照或失效路线|判断依据|
|---|---|---|---|
|01 边缘|切换阶跃、亮线、屋顶，拖动采样线|增加噪声，再增加平滑尺度|比较一阶峰、二阶零交叉与真实剖面；不要把候选数当准确率|
|02 Canny|单步查看NMS、双阈值与连接|默认强弱边界中查看孤立弱线消失|弱像素是否通过8邻域连到强边缘；高低阈值不是两个独立结果|
|03 角点|角点预设中移动窗口|切换直线边缘、平坦区；旋转与缩放分别比较|两个特征值和实际窗口SSD；边缘沿切向缺少约束|
|04 几何拟合|切换LS与RANSAC|离群点比例从0.2增至0.5；分别看直线、圆、椭圆|同一种几何残差和已知模型误差分别看；低全点残差不保证接近真值|
|05 亚像素|把位置从31.4连续移动到31.45|选无信号预设；另试宽度0.4、噪声40|无信号必须拒绝定位；重复试验偏差/标准差是实测，不承诺通用亚像素精度|
|06 Snake|清晰边界播放后单步看能量|弱边界、凹陷目标，或初始偏移80px|能量下降不代表贴到正确边界；初值远离目标可能停在局部最小|
|07 霍夫|选择全部点累加器后点击亮格|缺口0.8、步长8、噪声30；与步长1对比|选中格子的真实票数与回投影；票数较高的峰也可能偏离真值|
|08 SIFT|旋转30°后点击右图关键点|无纹理预设在旋转0、缩放1时查看；模糊作为另一个对照|高斯、DoG、细化、方向、128维描述子来自真实计算；缩放后的填充边界可能产生角点，不把它叫原始纹理|
|09 匹配|默认双帧单步看四层匹配|重复纹理，比值0.75；再与1比较|匹配不足可明确失败；几何内点率不是正确率，无独立真值的双帧不显示正确率|
|10 变换|依次切换刚体、仿射、投影|选择近共线配置|观察网格与重投影误差；四对点数量够不代表配置有效|

## 看过程和导出

- 过程下拉框选择实际阶段；播放/暂停和单步只浏览本次计算，不是重新制造结果。
- 三画布同步缩放；过程/结果拖动用于平移，输入画布可能用于编辑。Shift+拖动保留平移。
- PNG保存当前结果视图；JSON保存参数、固定种子42、分析尺寸与上传坐标映射。
- 上传图片只在本机处理；独立照片没有真值时不显示虚构正确率。
- 复位恢复默认案例和预览质量；高质量切换会清除旧分析坐标下的编辑点。

## 证据与限制

上述边界参数的数值观察见同目录 geometric-outlier、localization-boundary、snake-boundary、hough-boundary、sift-boundary、matching-boundary 的验证记录。浏览器部分行为已由回归覆盖，但这份操作卡本身不证明每一行已完成现场教学验收。实际30秒上手、课堂投影可读性和全场景失败案例浏览器检查仍需执行。未提供本章PPT，不填写虚构页码；不包含全景拼接或人脸模块。
