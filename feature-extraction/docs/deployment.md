# 启动与静态部署

## 本地使用

需要 Node 22 或更新版本。在项目目录运行 `npm run serve`，打开 `http://127.0.0.1:4180/`。运行网页本身不需要安装测试依赖；不要直接双击 `web/index.html`，ES Modules、同源 Worker 及照片加载需要 HTTP 服务。

先打开 `/?scene=01`，移动模糊参数即可开始实验。场景直链支持 `01` 至 `10`；例如 `/?scene=08` 为 SIFT，`/?scene=09` 为匹配，`/?scene=06` 为 Snake。教师模式使用 `/?scene=03&teacher=1`。

测试环境安装：`npm ci`。全量验证：`npm test`。浏览器测试使用已安装的 Google Chrome，不会自动安装浏览器。测试依赖不进入网页运行时。

## 构建与发布产物

本项目无需编译或打包，`web/` 即完整静态部署目录，需保留所有子目录与文件，不包含 `node_modules/`、测试、缓存或截图。

部署到已有网站的独立子路径时，将 `web/` 的内容完整放入该目录，例如 `/feature-extraction-lab/`。示例访问形式为 `/feature-extraction-lab/?scene=08`，不是单独发布某个 HTML 文件。所有运行资源均为相对路径；不要把 Worker 和算法模块移到另一个域名。

服务端需让 `.mjs` 返回 JavaScript MIME 类型、`.json` 返回 JSON 类型、`.jpg` 返回图片类型。对 HTML 使用短缓存或协商缓存；发布时同步替换整个静态版本，避免新页面加载旧算法模块。

## 发布验收

1. 在实际子路径打开十个场景，检查 HTML、CSS、入口模块、Worker、算法模块和两张实拍图片无 404。
2. 上传本地图片并完成一次参数调整、PNG 与 JSON 导出；检查无图片上传或第三方运行请求。
3. 复查高清计算后的复位、带留白画布的采样/拖动、取消任务和错误输入。
4. 桌面和手机宽度分别检查；浏览器尺寸模拟不能被声明为手机真机测试。
