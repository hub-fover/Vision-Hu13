# 霍夫累加器点击联动检查

日期：2026-10-06。

发现两个实际数据流问题：选中模型回投影后文字仍引用全局最高峰；点击位置使用连续角度和四舍五入映射，而热图使用向下取整的格子映射。

修复：选中模型的票数从相应累加器单元读取；点击使用与热图相同的 `floor(x / width * cols)` / `floor(y / height * rows)`，边界截断到最后一格。

验证证据：在 Node REPL 中直接调用生产模块并使用独立常量断言。选中零票直线/圆心的文字断言先失败，修复后两种情况通过。格子函数缺失时断言失败，实现后直线与圆的格子、右下边界四项断言通过。对应回归文件为 `tests/hough-selection.test.mjs` 和 `tests/hough-cell.test.mjs`。

范围：这里只验证了真实场景输出与坐标函数，不等同于浏览器点击验收或完整测试通过。完整测试启动仍受到 Windows `CreateProcessWithLogonW failed: 1909` 阻止。此前 69 项通过记录早于这些修改，也早于匹配真值提示修复，不能作为当前版本全绿证据。
