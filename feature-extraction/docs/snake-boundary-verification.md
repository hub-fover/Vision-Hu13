# Snake初始化与弱边界验收

2026-10-06备用JavaScript环境直接运行生产场景06，480×300，默认能量权重、步长1、上限80，清晰/弱/凹陷预设各比较初始水平偏移0与80。逐轮实际断言总能量不增加。

| 目标 | 初始偏移 | 初/末能量 | 径向边界RMS / px |
| --- | ---: | --- | ---: |
| 清晰 | 0 | −173.66 → −569.01 | 0.62 |
| 清晰 | 80 | 145.28 → 142.16 | 56.84 |
| 弱边界 | 0 | 179.25 → 179.25 | 6.00 |
| 弱边界 | 80 | 185.07 → 185.07 | 56.97 |
| 凹陷 | 0 | −78.88 → −496.16 | 5.74 |
| 凹陷 | 80 | 145.87 → 142.89 | 69.14 |

径向指标独立按合成真值半径81计算；凹陷使用半径81[1−0.4exp(−(θ/0.5)²)]，它是径向差，不是点到凹陷曲线的最短几何距离，不应与场景04的几何RMS混用。此指标只用于本验收，不插入上传照片的无真值界面。

六组均以“离散邻域局部稳定：没有降低能量的移动”停止。清晰偏移80仍降低能量，却远离正确边界；弱边界默认轮廓不动；凹陷即使能量明显降低，径向偏差仍约5.74px。成功与失效原因是实际捕获范围、内部约束和局部搜索，不是假演化动画。

本轮仅数值验证，仍需浏览器逐项操作和视觉检查。尤其trace包含一次无移动停止记录，不能将trace长度简单解释为实际移动轮数；当前界面显示的是计算迭代记录数。
