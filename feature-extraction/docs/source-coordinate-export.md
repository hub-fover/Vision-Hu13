# 原图坐标配置导出

JSON 新增 `sourceMappings.first` 和 `sourceMappings.second`，记录原图（浏览器方向校正后）尺寸、解码尺寸、分析尺寸及原图到分析图的 3×3 矩阵。合成样例没有原图时记为 null，不虚构原始尺寸。

矩阵使用零起点像素中心坐标。解码缩放按实际取整后的宽、高分别计算，因此可表达极窄图像或取整产生的两个方向差异。浏览器缩放的像素中心映射为 `x' = sx·x + (sx−1)/2`。第二图再叠加现有保持比例适配的比例与留白平移，不把两张不同长宽比的照片误记为简单同尺寸缩放。

640×360、原始1600×900的映射为两个方向 .4 倍、平移 −.3。原始1000×500解码为640×320、适配640×360时，两个方向 .64 倍，y 平移19.82。上述独立手算断言已通过直接调用生产函数验证。

元数据随同一次 Worker 任务返回，并从该任务导出，避免读取稍后控件状态推测旧结果来源。不包含图像像素、文件名或文件路径。已有双图浏览器测试增加导出断言；最新全量及下载链路仍待命令环境恢复后复验。
