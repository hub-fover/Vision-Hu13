# 亚像素定位失效示例：无信号

场景05新增“失效：无信号剖面（振幅/噪声固定为0）”。它实际生成常量剖面并运行同一个局部拟合器；拟合器根据真实对比度拒绝定位，返回“平坦剖面没有足够对比度”，不是预设一个虚构误差或随意位置。

该预设明确固定振幅和噪声为0，其他正常剖面仍遵循各控件。直接运行生产实现已验证：无信号被拒绝；恢复正常无噪声光斑时，31.4的中心误差小于 .001px。新增数值与浏览器失效/复位测试，浏览器测试尚未执行，全量再次受1909系统启动错误影响。

它说明无信号时位置不可辨识，不代表低信噪比在任意噪声分布下均能可靠判错。重复试验结果仍用于展示噪声下的实际偏差与波动，不能把“数值拟合返回”当成定位必然正确。
