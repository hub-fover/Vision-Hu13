## 架构

采用原生 ES Modules、Canvas 2D、同源 Worker 与静态资源。复用既有 LAB 白底、蓝色、灰色边框和参数侧栏，微软雅黑优先。桌面三幅同步画布：输入、过程、结果；手机纵向排列。路由使用 ?scene=01 至 ?scene=10，教师模式使用 ?teacher=1。默认加载可运行示例并执行一次计算。

公共计算请求包含 {id, scene, w, h, input, input2, options, seed, sourceMappings}，响应包含 {id, scene, w, h, input, result, timing, options, seed, sourceMappings}；result内保留stages、metrics、observation及场景实际数据。阶段图、指标、提示属于同一次任务。主线程忽略旧 id，长任务取消时终止并重建 Worker。算法模块不依赖 DOM，便于数值测试。

默认预览最长边640px，高质量1280px；上传文件32MiB、原始像素24MP，分析及结果画布各边最多1280，因此最大1.6384MP。超过分析尺寸会先缩小；原图或文件超过上限会明确拒绝。工作集256MiB是设计目标，未将返回缓冲区压力测试冒称峰值达标。JSON记录原始/解码/分析尺寸及像素中心变换矩阵。切换质量会本地重新解码所选文件，并清除旧分析坐标下的手工编辑点。数值矩阵不以显示归一化后的图片代替。

SIFT 必须验证实际实现与 128 维描述子；若现有 WASM 未导出，优先同源专用构建或真实 JS 实现，并核对算法阶段，不能用 ORB 代替。本版不包含拼接、人脸模型或摄像头入口。

## 场景与验收映射

|场景|课程知识点|必须检查的实际输出与失效案例|
|---|---|---|
|01|边缘类型、导数|采样线、灰度/一阶/二阶曲线、Sobel/Scharr/LoG；噪声导致候选增加|
|02|Canny|同次平滑、梯度、方向、NMS、双阈值、连接；孤立弱边缘消失|
|03|结构张量、Harris、Shi–Tomasi|特征值、响应、局部误差曲面、NMS；边缘方向歧义与尺度变化|
|04|几何拟合、RANSAC|直线/圆/椭圆、统一几何残差、已知真值；离群点拖偏 LS|
|05|亚像素定位|光斑中心和阶跃拐点分开、拟合、误差、重复偏差/标准差；低信噪比失败|
|06|Snake|清晰/弱/凹陷边界，实际迭代与能量、停止原因；初值敏感|
|07|Hough|直线与圆、累加器与点击峰值回投影、梯度约束；噪声峰与分辨率不足|
|08|SIFT|高斯/DoG/候选/筛选/主方向/128维描述子；模糊与极端尺度失败|
|09|匹配筛选|候选、比率、交叉、RANSAC 内点/重投影；重复纹理歧义|
|10|齐次坐标、变换|刚体/仿射/投影、网格、重投影、病态提示；近共线配置|

## 实施顺序与统一行为

1. 统一布局、路由、资源台账、Worker、画布同步、上传/复位/导出；实现 01、02、04、05、07、10。
2. 实现 03、08、09。先跑 SIFT 能力验证，再接入匹配和几何验证；提供真实案例，人工变换的有真值对照明确标注。
3. 实现 06；教师模式、手机基本操作、内存/取消恢复。

所有场景支持复位、原图/结果切换、对比、阶段单步和播放/暂停、PNG 与 JSON 配置导出。无迭代算法的单步切换实际处理阶段；迭代算法推进真实迭代。提示由当前指标生成，无真值不显示正确率。

## 验收门槛

- 数值：导数常量/斜坡、结构张量、LS/RANSAC 真值与固定种子、亚像素采样相位、Hough 真值、齐次重投影、坐标缩放一致性。
- 浏览器：10 场景打开即有真实结果；参数改变结果；复位一致；上传正常与失败；播放/暂停/单步；PNG/配置导出；桌面与手机；控制台与资源无错误。
- 可靠性：旧任务不能覆盖新任务；取消能恢复；上传后无图像外传；大图受控降采样。
- 素材：逐项来源、许可、修改、真实/合成分类；依赖版本/hash/许可；课程映射说明未提供 PPT。
- 交付：源码、启动/构建命令、知识点表、许可清单、实际操作记录与限制。未实际运行的项目不得标记 PASS。部署授权和目标确认后才发布，不能把本地验证称为线上完成。
