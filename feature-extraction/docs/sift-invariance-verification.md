# SIFT 端到端旋转与尺度验证

采用固定种子 19、256×256 的数值光斑纹理作为测试夹具，不作为公开实拍素材。原图和变换图分别完整运行生产 SIFT，再用生产欧氏距离、.75 比率和双向一致性筛选匹配。

真值坐标由独立的中心相似变换公式计算，没有调用变换实现返回的 map，也没有借助 RANSAC 重新拟合来降低真值误差。

备用 JavaScript 执行环境直接运行生产函数，得到：

|变换|双向匹配|误差小于 2px|中位坐标误差|
|---|---:|---:|---:|
|旋转 30°|64|63|0.1052px|
|缩放 1.3 倍|72|70|0.0831px|
|旋转 30° + 缩放 1.3 倍|61|53|0.1318px|

这是这一确定夹具上的实际结果，不是 SIFT 对任意场景的精度保证。联合变换仍存在错误匹配，不能承诺完全不变。新增 `tests/sift-invariance.test.mjs` 要求至少 20 对、至少 80% 对应误差小于 2px、中位误差小于 .5px；它可捕获描述子未正确归一化旋转/尺度或匹配到错误位置的问题。新增测试文件尚待完整测试命令复验，目前直接函数链路执行已有上述证据。
