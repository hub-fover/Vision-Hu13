# Worker 输入校验补强

## 实际问题

生产计算入口只在边缘分支检查输入长度，几何及特征分支提前进入算法。因此错误长度可能得到结构张量内部错误，非有限像素可能进入后续特征计算而出现不相关的参数错误。

## 修改

在场景分支之前统一验证第一张、第二张图片的整数尺寸、1280×1280 总像素预算、准确数组长度及有限像素值。第二图按现有 `input2 / input2Width / input2Height` 契约校验，不使用不存在的嵌套字段。

## 证据与限制

通过备用 Node 执行环境直接导入生产 `compute.worker.mjs`，调用原有消息入口，捕获消息输出。修复前，错误长度返回“结构张量尺寸或窗口尺度无效”，NaN 输入返回不相关的 sigma 错误。修复后，三种输入分别返回“输入长度与尺寸不一致”“输入像素必须为有限数值”“输入长度与尺寸不一致”，断言通过。

此检查只验证生产入口及算法路由，消息接收端由测试捕获；不等同于浏览器 Worker 验收。`tests/worker-input.test.mjs` 已增加真实浏览器测试，但尚未完成运行。系统命令启动仍失败（CreateProcessWithLogonW 1909）；完整回归不得声明通过，最近一次全量结果仍是此修改之前的 53 项通过。

后续复验：环境短暂恢复后运行完整 `npm test`，56 项通过、0 失败、0 跳过。真实 Chrome 中的 `worker-input.test.mjs` 实际通过，三个错误输入均由生产 Worker 返回预期错误。因此上段是中断时的历史状态，不是当前验收状态。
