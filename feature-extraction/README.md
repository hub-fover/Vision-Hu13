# 特征提取 LAB

首次课堂使用可按 `docs/classroom-walkthrough.md` 的十场景操作卡进行；其中区分成功路线、失效对照和观察指标，不把操作说明冒称已完成验收。

研究生课堂的浏览器本地算法实验。01–10均已接入：边缘、Canny、角点、几何拟合、亚像素定位、Snake、霍夫、实际SIFT、匹配与几何变换。按用户最新要求不含图像拼接和人脸模块。完整验收仍在推进，不能把入口接通等同全部交付。

09默认使用真实山景视频5.64s/8.48s两帧，来源为cottonbro studio/Pexels。可分别上传第一张与第二张照片；第二张保持比例适配分析画布。不上传图片，也不为独立双图显示虚构正确率。人工变换对照作为单独预设保留。

06点击“绘制初始轮廓”，在输入画布按住画一圈，松手闭合并开始实际演化；轮廓等距重采样为40个控制点，交叉或近零面积会拒绝。也可拖动已有控制点。输入图普通拖动在其他场景用于采样或编辑；Shift+拖动保留为平移。

启动：Node 22+，在本目录运行 `npm run serve`，打开 http://127.0.0.1:4180/ 。静态页面需 HTTP 服务，不能直接双击 HTML。

场景直链支持 `/?scene=01` 至 `/?scene=10`，包括 `03` 角点、`06` Snake、`08` SIFT 和 `09` 匹配；教师模式添加 `&teacher=1`。画布同步缩放；拖动过程/结果画布平移；01 点击/拖动输入画布调整采样线，04/07 点击添加点、拖动已有点，10 拖动输入/结果的对应点。Shift+拖动用于平移。单步和播放展示同一次计算的真实阶段。

安装测试依赖：`npm ci`。数值测试：`npm run test:numeric`。浏览器验收：`npm run test:browser`（Playwright 1.62.0 使用已安装的 Google Chrome；浏览器运行网页无需 npm 或第三方运行时）。

PNG 导出当前结果视图；JSON 导出计算参数、种子、尺寸和实际耗时。上传图像只在浏览器解码；不上传服务器。切换计算质量会在本机重新采样已选照片，双图同步更新；由于像素坐标系改变，手工编辑点与视图会清除。内置山景及来源记录见 `web/assets/manifest.json`，第三方照片仍按 Pexels License 管理。

范围、知识点映射和验收门槛见 `docs/design-and-acceptance.md`；实际验证见 `docs/verification.md`。尚未完成的场景没有伪装成可用入口。当前未部署公网。
