## 📱 使用示例数据（最快体验）

### 步骤1: 打开标定页面
[calibration.html](http://localhost:8006/calibration.html)

### 步骤2: 加载示例

等待标定完成（约2-5秒）

标定成功后会显示：
- ✅ 重投影误差: 0.503 像素
- ✅ 焦距: fx=532.8, fy=532.9

### 步骤5: 进入测量
点击 **"进入测量模式"** 或直接访问 [measurement.html](http://localhost:8006/measurement.html)

## 📏 使用测量功能

### 距离测量
1. 选择 **"距离测量"** 模式
2. 启动相机（或加载示例标定数据）
3. 在画面中点击两个点
4. 实时显示距离（毫米）

### 矩形测量
1. 选择 **"矩形测量"** 模式
2. 启动相机
3. 在画面中依次点击四个角点
4. 显示矩形的长和宽（毫米）

## 🎯 使用自己的相机

### 准备工作

#### 1. 打印棋盘格标定板
- 下载: [checkerboard-9x6.pdf](assets/checkerboard-9x6.pdf)
- 打印设置:
  - 纸张: A4
  - 不缩放（100%）
  - 方格边长: 约25mm
- 建议贴在硬纸板上保持平整

#### 2. 准备拍摄环境
- 良好的光照（避免反光）
- 平稳放置相机或手机
- 清晰的棋盘格视野

### 标定流程

#### 步骤1: 启动相机
访问 [calibration.html](http://localhost:8006/calibration.html)

点击 **"启动相机"**

授予相机权限

#### 步骤2: 采集图像
对准棋盘格，调整位置和角度，当检测到角点时：
- 画面显示绿色圆点和编号
- 点击 **"拍摄"** 按钮

**拍摄技巧**:
- ✅ 棋盘格充满画面的50-80%
- ✅ 多角度: 正面、左侧、右侧、上方、下方
- ✅ 多距离: 近、中、远
- ✅ 多倾斜: 轻微倾斜各个方向
- ❌ 避免模糊、遮挡、反光

**推荐数量**: 10-20张（15张最佳）

#### 步骤3: 开始标定
采集完成后，点击 **"开始标定"**

等待计算完成

#### 步骤4: 检查结果
**重投影误差**:
- 😊 < 0.5 像素: 优秀
- 😐 0.5-1.0 像素: 良好
- 😕 > 1.0 像素: 建议重新标定

如果误差过大:
- 点击 **"清空图像"** 重新采集
- 确保图像清晰、角点检测准确
- 增加图像多样性（更多角度）

#### 步骤5: 保存并测量
标定成功后数据自动保存到浏览器

进入测量页面开始使用

## ⚙️ 配置说明

### 棋盘格参数
```javascript
// 默认配置（在calibration.html中）
boardWidth = 9   // 内角点列数
boardHeight = 6  // 内角点行数
squareSize = 25  // 方格边长（毫米）
```

**如何修改**:
1. 打开浏览器开发者工具（F12）
2. 在Console中输入:
```javascript
boardWidth = 你的列数;
boardHeight = 你的行数;
squareSize = 你的方格边长;
```

### 相机分辨率
```javascript
// 在measurement.js中
const constraints = {
    video: {
        facingMode: 'environment',  // 后置摄像头
        width: { ideal: 1280 },
        height: { ideal: 720 }
    }
};
```

## 🔧 常见问题

### Q1: 点击"启动相机"没反应？
**A**: 检查浏览器权限设置
- Chrome: 地址栏左侧 → 网站设置 → 相机 → 允许
- 必须使用HTTPS或localhost

### Q2: 检测不到棋盘格角点？
**A**: 
- 确保棋盘格完整、平整、清晰
- 调整光照（避免阴影和反光）
- 调整距离（不要太近或太远）
- 确认配置正确（9×6）

### Q3: 标定误差很大（>1.0像素）？
**A**:
- 删除模糊或角点检测不准的图像
- 增加角度和距离的多样性
- 确保所有图像都使用同一相机

### Q4: 测量结果不准确？
**A**:
- 首先确保标定误差 < 0.5像素
- 测量平面物体（非曲面）
- 测量距离在标定时的距离范围内
- 标定和测量使用相同的焦距（不要缩放）

### Q5: 加载示例数据失败？
**A**:
- 检查网络连接
- 确认文件路径: `assets/samples/left01.jpg` 等
- 打开浏览器Console查看错误信息

### Q6: OpenCV.js加载失败？
**A**:
- 检查网络连接（需要访问docs.opencv.org）
- 等待加载完成（首次约需10-30秒）
- 刷新页面重试

## 📊 技术参数

### 系统要求
- **浏览器**: Chrome 90+, Firefox 88+, Safari 14+
- **相机**: 500万像素以上
- **网络**: 首次加载需下载OpenCV.js (约8MB)

### 性能指标
- **角点检测**: 30-60ms/帧
- **标定计算**: 2-5秒（15张640×480图像）
- **测量延迟**: < 50ms

### 精度范围
- **标定误差**: 0.3-0.8像素（示例数据）
- **测量精度**: 1-2mm @ 1米距离（理论值）
