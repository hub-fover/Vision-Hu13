# 真实图片实验教师指南

现提供9个真实数据实验，不再显示合成图与机制演示。004/03单目深度；005/02双目、03光流；006/01帧差、02跟踪、04分割；007/03照片分类训练；008/01迁移、02检测。

先选实拍样例，预测一个参数的影响，再运行、导出PNG/JSON并解释失效。旧实验链接自动转到本章首个保留实验。

- 双目：选纹理、弱纹理和遮挡区，比较窗口和搜索范围。
- 光流/跟踪：比较金字塔和窗口，观察运动边缘的跟踪失效。
- 帧差/分割：阈值掩码不是目标标签，颜色聚类不是语义分割。
- 分类/迁移：不同照片分别标A/B，观察真实损失下降，使用独立图片测试泛化。
- 检测：观察阈值造成的漏检/误检，模型置信度不等于准确率。
- 深度：运行既有LAB007 DepthAnything，检查玻璃、镜面、遮挡边缘；输出相对深度。

图像只在本机处理。DepthAnything扩展需要联网，其余真实计算运行时与权重均随站点发布。教师模式追加&teacher=1。


## 连续媒体与手机相机（2026-10-10）
005/03、006/01、006/02 支持 2–120 张同尺寸图片（文件名数字排序）、本地视频（MP4 H.264 / WebM，浏览器可解码）和 HTTPS 页面相机。默认样例为 OpenCV vtest.avi 前 6 秒行人实拍视频及 30 帧序列。工作分辨率最高 384×288；采样 2/5/10 fps，最多 120 帧，视频达到上限只处理前段。图片序列时间按用户设置帧率估算。

相机：展开相机面板并点击“打开相机”，授权后选择连续拍照或实时分析；“关闭相机”、取消、运行回放、切换章节都会停止媒体轨道。前后镜头切换重新初始化背景或轨迹。手机推荐系统 Chrome/Safari；浏览器能否开放权限取决于设备和浏览器，应用不会上传画面。实时模式忙碌时跳帧，以实际采集时间戳计算像素速度，保留最近 60 个结果。

深入任务：比较不同帧率、LK 前后向阈值与补点开关；分析同一特征轨迹寿命、失效数与保留率。背景模型对比相邻帧差，切换前景冻结及 α，观察静止物体被背景吸收；相机移动会破坏固定背景假设。没有人工标注时只报告测量值，不报告准确率。特征 ID 不是人物 ID，像素/秒不是物理速度。时间轴、单步、定时播放、曲线、PNG 和含逐帧参数/指标/轨迹的 JSON 来自同一次运行。

验收包含真实 MP4 解码与浏览器 MediaStream 测试流的权限、拍照、实时、镜头切换和释放；物理手机相机仍应在实际设备上验证。
