# Browser OSS models

The bundles are pinned TensorFlow.js 4.22.0 and @tensorflow-models/coco-ssd 2.2.3, both Apache-2.0. LICENSE-TFJS.txt and LICENSE-MODELS.txt contain their license texts. Their upstreams are https://github.com/tensorflow/tfjs and https://github.com/tensorflow/tfjs-models. `manifest.json` records exact downloaded URLs, byte counts and SHA-256 hashes.

MobileNet V1 alpha 1.0, input 224, is the official TensorFlow.js legacy Keras/layers export from https://storage.googleapis.com/tfjs-models/tfjs/mobilenet_v1_1.0_224/model.json. This version is used deliberately because the newer tfhub.dev download links redirect to Kaggle HTML in this environment. `tf.loadLayersModel` executes the actual pretrained network; normalized RGB input is [-1,1]. `global_average_pooling2d_1` supplies 1024-dimensional embeddings, and the full network supplies ImageNet softmax outputs. ImageNet label names are derived from the upstream MobileNet class table. Its model artifacts are distributed by the TensorFlow project under Apache-2.0; ImageNet photographs are not redistributed here.

COCO-SSD lite_mobilenet_v2 uses the official saved graph and five original shards from https://storage.googleapis.com/tfjs-models/savedmodel/ssdlite_mobilenet_v2/model.json. Its runtime already performs an upstream NMS; the interface applies an additional class-aware NMS to returned candidates. The score and NMS controls affect real predictions; IoU here measures box overlap, never accuracy. No ground truth or mAP is provided.

Photographs are copied byte for byte from the existing lab-007 verified sample set. `photos.json` retains creators, original pages, licenses, modifications, dimensions and original SHA-256 checksums. person.jpg is Wilfredor, Street Craftsman in Olinda, CC0 1.0. indoor.jpg is Lisa Anna, TV in a Living Room, Pexels License. street.jpg is a frame from Zulfugar Karimov, Panoramic Cityscape of Modern Urban Skyline, Pexels License. These photos retain their original licenses, independently of source-code licenses.

All runtime dependencies, weights and sample photos are served from the same origin. No request to Google, npm, GitHub or other external hosts is made during inference. User uploads are processed locally and are not transmitted. Maximum upload 20 MB / 40 million pixels; failed decode reports in the interface. The shared cached networks are reused between scenes; temporary input, embedding and prediction tensors are disposed after each inference.
