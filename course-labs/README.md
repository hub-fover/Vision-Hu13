# Vision Hub 课程实验室

五章独立入口，24个核心实验。按用户提供的004–008课件编排，运行代码、数值、合成数据和中间状态均在当前浏览器计算。大型模型内容采用明确标注的简化机制，不要求安装Python，也不加载大模型权重。

## 启动

仓库根目录运行 `npm run build:course`，然后 `npm run serve:course`。打开 `http://127.0.0.1:4188/course-labs/`。也可直接运行 `node course-labs/scripts/build.mjs`、`node course-labs/scripts/serve.mjs`。ES模块与Worker需要HTTP服务，不可双击HTML运行。

章节路径为 `course-labs/chapter-004/` 至 `chapter-008/`。参数 `?scene=01` 选择实验，`&teacher=1` 打开教师说明。非法实验编号退回本章第一个实验。

## 教学和计算范围

|章节|实验及边界|
|---|---|
|004|局部反射、标定光度立体、坡度SFS机制、合成焦点序列、Gray/四步相移。SFS为简化坡度模型；相移输出投影坐标而非未经标定的物理高度。|
|005|已知姿态的受约束标定、平行双目极线与三角化、全局平移LK、固定相机的三维点优化。不是完整Zhang标定、未知相机SfM或联合BA。|
|006|像素帧差与背景、NCC与Kalman、小规模全局关联、灰度聚类、PCA图块。Mean Shift采用64-bin灰度近似；图块匹配不是深度ReID。|
|007|合成划分、实际梯度下降、分类器、XOR反向传播、可训练卷积核的小CNN。训练集准确率与测试集准确率分别标注。|
|008|小网络迁移、几何检测分割指标、精确小矩阵注意力、线性AE和一维学习噪声预测器、人工属性投影对齐。不是预训练ViT、DETR、CLIP或VLM应用。|

所有实验均有已计算的实际阶段。播放用于查看同一次计算的阶段，并非在线训练计时。指标描述整次计算的最终结果，阶段画布用于观察过程。不同阶段的图像色条可能具有不同范围，不应仅凭颜色判断幅值变化。

三维表面可拖动或使用方向键旋转。保存对照后改变参数，用“查看对照”切换结果。PNG导出当前阶段与参数，JSON导出完整数值、阶段、参数、种子、计算耗时和课件页码；两份文件一起保存更便于复现。

## 图像输入与隐私

只有标明支持自选图像的实验显示上传入口。支持PNG/JPEG/WebP，文件上限16MiB、解码后2400万像素；分析最长边64像素并转换灰度。图像不外传、不写入持久化存储。JSON导出包含用于计算的灰度像素及文件名，由学生主动下载。

聚类与PCA自选图像没有人工真值，不显示正确率；LK对自选图像施加已知人工平移，其误差只对应此人工变换，不评价真实视频运动。

## 验证和部署

`npm run test:course:numeric` 运行数值测试，`npm run test:course:browser` 用Playwright与Chrome检查24个入口、控件、导出和移动尺寸，`npm run validate:course` 检查发布目录。`npm ci` 安装测试依赖；网页本身无需npm。

构建生成 `web/course-labs/`，完整复制该目录即可部署静态网站。采用相对资源路径，与GitHub Pages子路径兼容。根仓库原有Lab不会被构建脚本修改。CI先检查课程数值与浏览器行为，再由现有Pages流程发布。

源码模块位于 `course-labs/chapters/`；界面不内嵌算法。Worker每次任务独立创建，参数变化、取消与复位终止旧Worker；任务编号阻止旧结果覆盖新任务。超时30秒自动停止，可调整参数重新运行。

素材与许可见LICENSES.md，教师操作见TEACHER.md。浏览器尺寸模拟不是手机真机验收。
